# Product scope: prototype vs future

**Delivered within the one-day competition MVP**

- Learner-facing bilingual responsive web app; one-click isolated demonstration.
- Concept map and adaptive learner profile.
- Deterministic, mathematically checked RDM2 beam simulation.
- Predict → solve → teach-back → new transfer cycle.
- Misconception classification and repeat warnings.
- PDF upload, per-page rendering and activity tracking.
- Optional Socratic LLM coach with structured excerpts; rule-based default.
- Curated official university/open-education resource links.
- Automatic tests, architecture, four-minute demo script.

**Explicit non-goals for this prototype**

- Measuring or proving actual educational improvement.
- Real-time YouTube/TikTok/Instagram scraping or automatic social discovery.
- Grade predictions, psychological profiles, or surveillance of students.
- Production GDPR compliance, institutional onboarding and SSO.
- Any beam topology beyond a simply supported span with a point load and full-span UDL.
- OCR, Office imports, live video ingestion or real-time knowledge graph extraction.
- Fully validated AI-written response grading.

**Next quality gates**

1. Add accessible focus testing and real-browser E2E checks on Windows/macOS.
2. Have a CNAM RDM2 instructor validate all exercise cases and French terminology.
3. Add explicit consent modal before sending course excerpts to any external LLM.
4. Add optional import of a teacher-reviewed concept-to-resource mapping.
5. Create teacher-controlled anonymized pilot, a deletion endpoint and audit trail.
